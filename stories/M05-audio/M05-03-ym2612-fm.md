# M05-03 · YM2612 FM synthesis (ymfm)

**Milestone:** [M05 – Audio](README.md)  
**Status:** Draft  
**Depends on:** M05-01  
**Spec refs:** [06-audio](../../docs/specs/06-audio.md#ym2612-fm)

## Story

As a **developer**, I want YM2612 FM synthesis using ymfm behind an `IFmSynth` interface, so that music sounds right without writing an FM core from scratch.

## Scope

- Integrate `ymfm::ym2612` (vcpkg or vendored in `third_party/` with license notice)
- `IFmSynth`: write/read_status/generate/serialize
- Register port interface (A0/D0/A1/D1), busy flag
- Catch-up clocking at MCLK/7

## Acceptance criteria

- [ ] Sonic 1/2/3K title music matches reference recordings by ear and within tolerance in the WAV comparison
- [ ] FM state round-trips through save states
- [ ] ymfm license listed in `THIRD_PARTY_NOTICES.md`

## Test plan

- WAV comparison tests
- Save-state round-trip test
