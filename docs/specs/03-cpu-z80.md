# 03 · Zilog Z80 CPU

## Requirements

| ID | Requirement |
|----|-------------|
| CZ-1 | Implement the full Z80 instruction set: unprefixed, CB, ED, DD, FD, DDCB, FDCB, **including undocumented** instructions (IXH/IXL/IYH/IYL, SLL, DDCB register copies) and the undocumented X/Y flags (bits 3 and 5). |
| CZ-2 | Instruction-atomic `step()` returning T-states, including taken/not-taken conditional timing and block-instruction repeat timing. |
| CZ-3 | Model R register (7-bit increment per M1, bit 7 preserved), I register, IFF1/IFF2, interrupt modes 0/1/2, HALT, EI delay (interrupts not accepted immediately after EI), and WZ/MEMPTR (for test parity). |
| CZ-4 | Genesis uses **IM 1**: the VDP asserts the Z80 /INT at V-blank for approximately one scanline (≈ 171 Z80 cycles; model as "asserted for one line"). NMI is unused but implemented. |
| CZ-5 | Pass **ZEXDOC** and **ZEXALL** (run headless via a minimal CP/M BDOS shim) and the [SingleStepTests z80](https://github.com/SingleStepTests/z80) JSON suite. |
| CZ-6 | Call `onInstr` / `onAccess` hooks like the 68k, with `CpuId::Z80` and Z80-local addresses. The bus additionally reports the **translated 68k address** for banked-window accesses so ROM coverage can attribute them. |
| CZ-7 | Z80 can be held in reset and can be bus-requested by the 68k (spec 04); while either is asserted, `step()` does not execute. |

## Implementation approach

- Separate decode tables per prefix; DD/FD reuse HL handlers parameterized on the index register.
- `BusZ80` interface: `read8`, `write8`, `in8`, `out8` (I/O ports are unconnected on Genesis; reads return `$FF`).
- Accesses to the 68k bank window (`$8000–$FFFF`) incur a 68k bus stall; at instruction accuracy, charge an approximate penalty to the Z80 (≈ 3.3 Z80 cycles per access) and to the 68k (≈ 11 68k cycles), both configurable.

## Disassembler

- Zilog syntax compatible with AS (`ld (ix+$05),a`), covering all documented and undocumented opcodes.
- Same output structure as the 68k disassembler (length, targets, flow type).
