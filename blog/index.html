How genesisEmu is built

genesisEmu is a hand-written Sega Genesis emulator for reverse-engineering and modding the Sonic games. The project is written spec-first: every feature starts as a short story with acceptance criteria. This series has one article per finished story. Each one covers what the feature does, why an emulator needs it, and how this code base builds and tests it.
