When things go wrong, and when the screen wants attention

Exceptions and interrupts are how the 68000 reacts to the outside world and to its own mistakes. On the Genesis, every frame starts with one.

genesisEmu build notes5 min readStory M01-10

An exception is the 68000's way of dropping what it's doing and running a handler. Some come from inside the program: a TRAP instruction, a division by zero, an illegal opcode, an odd address. Others come from outside: an interrupt, or the reset line. Every handler address sits in the vector table, the first 1 KB of memory, which on the Genesis is the start of the cartridge ROM.

For a Genesis emulator, interrupts aren't an edge case. The video chip raises a vertical interrupt at the start of every frame's blanking period, and nearly every game runs its main per-frame work from that handler. Some also use the horizontal interrupt, for example to change palettes partway down the screen for water effects. M01-10 built the complete exception model.

Groups and frames

Most exceptions are handled the same way: switch to supervisor mode, clear the trace bit, push the PC and the old status register (a six-byte frame), read the handler address from the vector table and refill the prefetch queue there. One helper does it:

TRAP, TRAPV, CHK, zero-divide, illegal instructions, line A and line F, privilege violations and trace all go through it, each with its own vector, its own stacked PC (the faulting instruction or the next one, depending on the exception) and its own idle time.

The address error is different

An odd word access raises a group 0 exception, the most severe class. It stacks a 14-byte frame instead of 6, because the handler needs to know what went wrong:

Address errors happen in the middle of an instruction, so the core implements them as a C++ exception thrown from the bus primitive and caught in step(). The catch handler builds the frame word by word and charges 50 cycles on top of whatever the instruction had spent up to the fault. Because every access charged its time as it happened (M01-01), "whatever it had spent" is already right.

If writing the frame itself faults, because the stack pointer is odd too, the real chip gives up with a double bus fault and halts until reset. The core does the same: a second AddressErrorTrap inside the handler sets halted.

On the Genesis, every frame starts with an interrupt. Getting interrupts exactly right isn't an edge case.

Interrupts

The 68000 has three interrupt input pins, giving priority levels 1 to 7. The emulator sets the level with setIrqLevel, and step() samples it between instructions, as the chip does. A level is taken only if it's above the 3-bit mask in the status register. Level 7 is special: it can't be masked, and it's edge-triggered, so holding the line at 7 doesn't re-interrupt forever:

Taking an interrupt runs an acknowledge cycle on the bus, where the hardware can supply a vector number. On the Genesis the answer is always "autovector": level N uses vector 24+N, so the level-6 vertical interrupt lands at address $78. The bus interface can also return a specific vector or a spurious interrupt (vector 24), and both are supported. Taking an autovectored interrupt costs 44 cycles. The interrupt raises the mask to its own level, so the handler isn't re-entered by the same source, and the onIrq hook reports the level for the debugger.

Reset and trace

Reset reads the initial supervisor stack pointer from $000000 and the initial PC from $000004, which is how a Genesis cartridge's first eight bytes start the machine. Trace mode (the T bit) raises an exception after every instruction, which a debugger can use for single-stepping.

Tested both ways

The SingleStepTests suite covers TRAP, CHK and TRAPV (24,195 vectors) and every address error in the word and long files, and all pass, including frames and cycles. The suite has no ILLEGAL file, never sets the trace bit and never raises interrupts, so unit tests cover the rest:

  • Autovectored interrupts respect the mask: level 6 with mask 3 vectors to $78 in 44 cycles with the right frame; with mask 6 the CPU keeps executing.
  • Level 7 is edge triggered and not maskable.
  • Reset loads SSP from $0 and PC from $4.
  • Trace exception follows each instruction while T is set: a NOP plus trace takes 4 + 34 cycles.
  • Odd word access raises an address error with a group 0 frame: 50 cycles, SP lowered by 14, and the status word's low bits read $15 (read, data access, supervisor data).

One known gap is written down rather than hidden. When TRAP, CHK, TRAPV or a zero-divide happens with the trace bit set, real hardware takes a second exception for the trace, and the core doesn't. None of the target games trace their own code, so it's noted for later.
